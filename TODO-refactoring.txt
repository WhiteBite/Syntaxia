# Syntaxia - TODO Refactoring Plan (AAA+ Quality)

## Цель
AI Chat с Tool Calling: чат который может редактировать файлы с preview изменений и rollback.

## Архитектура целевого flow

```
User Message 
  → Smart Context (автоматический сбор связанных файлов)
  → AI Chat (tool calling: read/write/search)
  → File Changes (sandbox)
  → Verification (build/lint/test)
  → Self-Correction (если ошибки)
  → Preview Diff
  → User: Apply / Rollback
```
